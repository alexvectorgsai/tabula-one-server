# Tabula One для организаций

Независимая установка на Linux-сервер учебного центра. Аккаунты, материалы,
расписания, записи и видеосвязь обслуживаются на сервере организации.
Преподаватели и ученики работают в браузере.

## Текущий выпуск

**server-beta-2026.10.31.1 · приложение v0.2.32-beta.20261031**

- Удаление всех занятий одного дня освобождает его еженедельное время; сохранённое пустое правило заменяется при повторном размещении.
- Из личных уроков и группы доступна кнопка «К группам».
- Верхняя часть календаря компактнее, для расписания остаётся больше места.
- На телефоне имя говорящего появляется рядом с языком без скачков шапки.
- Нижние кнопки увеличены до размера микрофона и камеры, высота панели сохранена.
- Сетка календаря открывается с 12:00; утро и ночь доступны прокруткой.
- Расписание учеников и групп с общим количеством занятий и недельными повторами.
- 8 занятий дважды в неделю = 4 недели. Время и длительность меняются с шагом 30 минут.
- Проведённое отмечается зелёным, переносы — красным. Есть общие и индивидуальные заметки.
- Перенос без даты оставляет отметку и добавляет занятие в конец графика.
- Ctrl/Cmd и Shift выбирают несколько занятий для массовых действий; доступна отмена.
- «Перейти» открывает материалы ученика или группы для подготовки урока.
- Расписание сохраняется автоматически на сервере организации.

Также доступны PDF и доска, совместные пометки, медиа, видеозвонки, домашние
задания и архив уроков. Сохранены последние исправления мобильных настроек текста
и компактных панелей PDF/доски. Мини-карта доски удалена.

## Скачать и установить

1. Подготовьте Linux x86_64 с Docker Compose, публичный IPv4 и три поддомена.
2. [Скачайте комплект](https://github.com/alexvectorgsai/tabula-one-server/releases/download/server-beta-2026.10.31.1/tabula-one-server-v0.2.32-beta.20261031-bundle.1.tar.gz)
   и [контрольную сумму](https://github.com/alexvectorgsai/tabula-one-server/releases/download/server-beta-2026.10.31.1/tabula-one-server-v0.2.32-beta.20261031-bundle.1.tar.gz.sha256).
3. Выполните [пошаговую инструкцию](INSTALL.md), создайте администратора.
4. Примените JSON-разрешение в «Администрирование → Бета-доступ установки».

Нужен архив `…bundle.1.tar.gz`: автоматические архивы GitHub «Source code» его
не заменяют. В архиве есть все пять образов и [инструкция по расписанию](SCHEDULE.md).

## Обновление

Сначала создайте проверенную резервную копию. Распакуйте новый комплект рядом
со старым и следуйте INSTALL.md. Сохраняйте прежние `.env`, `.secrets`, ID,
имя проекта и тома; configure повторно не запускайте.

Обновлены app/shared и public-edge/web. Новых миграций нет (остаются 50). PostgreSQL, Garage и LiveKit остаются прежних версий;
аккаунты, материалы и действующее beta-разрешение сохраняются.

## Бесплатный бета-доступ

Начальный ориентир — 30 дней с продлением. Срок выдаёт представитель Tabula One.
Применяйте новый файл с тем же ID: оставшиеся дни сохраняются, переустановка
не требуется. Организация оплачивает сервер и домен.

Публичные DNS, HTTPS и звонок с двух устройств проверяются на сервере каждого
центра. Физический телефон и Safari остаются отдельной приёмкой.

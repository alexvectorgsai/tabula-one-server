# Обновление установленного сервера Tabula One

Постоянная страница: [tabulaone.uz/server#updates](https://tabulaone.uz/server#updates).
Администратор выбирает время установки. У преподавателей и учеников программа
остаётся в браузере, переустанавливать её на компьютерах не нужно.

## Если команда обновления уже есть

Из существующей папки комплекта:

```bash
./tabula update check
./tabula update install
```

Первая команда только проверяет наличие подписанного совместимого выпуска.
Вторая загружает небольшой пакет приложения, используя уже установленные
Docker-образы. Node.js на сервер отдельно устанавливать не требуется.

## Первый запуск обновлятора на прежнем комплекте

Самый простой вариант — кнопка **«Скачать обновление»** на странице обновлений.
Она скачивает один архив с обновлятором, подписанным описанием и самим пакетом.
Создайте отдельную папку, распакуйте архив и запустите:

```bash
mkdir -p /папка/обновлятора
tar -xzf tabula-one-update-2026.10.31.2.tar.gz -C /папка/обновлятора
bash /папка/обновлятора/update.sh --installation=/папка/Tabula install --release=/папка/обновлятора/latest.json --payload=/папка/обновлятора/payload.json.gz
```

Для следующих выпусков имя архива будет другим; берите его со страницы.
Этот вариант работает и без доступа сервера к интернету.

Можно скачать только обновлятор, чтобы он сам получил последний пакет:

На странице обновлений скачайте **обновлятор для существующей установки**,
распакуйте его в отдельную папку и укажите прежнюю папку Tabula One:

```bash
tar -xzf tabula-one-updater.tar.gz -C /папка/обновлятора
bash /папка/обновлятора/update.sh --installation=/папка/Tabula check
bash /папка/обновлятора/update.sh --installation=/папка/Tabula install
```

Папка `/папка/Tabula` должна содержать прежние `tabula`, `BUNDLE-MANIFEST.json`,
`IMAGES.tsv` и `deploy/server/.env`. Замените пути своими. Не запускайте
`configure`, не создавайте новый ID и не переносите данные в другую установку.
После успешного обновления доступна обычная команда `./tabula update`.

## Как проходит установка

Обновлятор проверяет цифровую подпись, контрольную сумму, исходную версию,
образы и схему базы. Сначала подготавливаются новые образы; действующая версия
продолжает работать. Установка блокируется, пока есть активные уроки, участники
или незавершённые записи. База, хранилище и видеосервис должны быть запущены.

На время переключения применяется режим обслуживания. Сохраняются резервная
копия БД, конфигурация, секреты и прежние контрольные файлы; проверяются ID,
разрешение и неизменность томов. Проверки новой версии выполняются до открытия
сайта для изменений. При ошибке запуска возвращается прежнее приложение.
База автоматически не откатывается: совместимое малое обновление не меняет
миграции, а возврат старой копии БД мог бы удалить более свежие данные.

Не удаляйте `.tabula-updates`: там находятся журналы, резервные копии и файлы
восстановления. Они остаются на сервере и могут содержать секреты; храните
папку с доступом только для администратора. Нужна также регулярная резервная
копия вне сервера, включая файлы Garage и записи: копия БД в папке обновления
не заменяет полное резервное копирование организации.

## Восстановление после прерывания

```bash
./tabula update rollback
```

Если прежний комплект ещё не поддерживает эту команду, используйте скачанный
обновлятор с `--installation=... rollback`. Путь к сохранённой копии обновлятора
также выводится при ошибке. Откат требует отсутствия активных уроков.
Если автоматическое восстановление не завершилось, сохраните папку обновления
и её журнал для администратора; повторная установка поверх томов не нужна.

## Без доступа сервера к интернету

Скачайте со страницы обновлений `latest.json` и указанный в нём пакет
`tabula-one-update-….json.gz`. Перенесите оба файла на сервер:

```bash
./tabula update install --release=/путь/latest.json --payload=/путь/пакет.json.gz
```

Подпись и совместимость проверяются точно так же. Не редактируйте эти файлы.

## Совместимость

Первая версия механизма рассчитана на совместимые исправления приложения,
без изменения зависимостей, инфраструктуры и миграций. Для неподдерживаемой
исходной версии либо изменения схемы обновлятор останавливается до переключения
и предлагает инструкцию выпуска. Переход через такие изменения выполняется
отдельным полным комплектом и не выдаётся за безопасное малое обновление.

Уже применённая папка содержит локально подготовленные новые образы и не
предназначена для переноса на другой сервер как установочный архив.
Для нового сервера используйте полный комплект, опубликованный отдельно.

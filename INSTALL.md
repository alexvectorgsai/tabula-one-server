# Установка готового серверного комплекта Tabula One

Комплект `2026.10.24.3`, основа приложения `v0.2.20-beta.20261024`.
Цель: Linux x86_64. На сервере не нужны Git, Node.js и доступ к репозиторию
разработки. Преподаватели и ученики работают через браузер.

Месячный доступ и продление реализованы подписанным файлом. Перед внешней выдачей
нужны приёмка целевого сервера и условия сторонних бинарников.

## Требования

- Linux-сервер с Docker Engine и Docker Compose 2.24.4+.
- Bash, sha256sum, tar, getent, ip, ss, df, free.
- Постоянный публичный IPv4, управление DNS и три A-записи: сайт, media, TURN.
- Входящие TCP 80/443/7881, UDP 7882 и UDP 30000–30099. SSH сохранить;
  БД и служебные административные интерфейсы наружу не публиковать.
- Свободный диск под распакованный комплект, образы, БД, файлы и записи.

Ориентир прежнего стенда: Ubuntu 24.04 LTS, 6 vCPU, 8 ГБ RAM, диск 150 ГБ.
Это не гарантия количества групп. Бесплатность беты не включает оплату сервера.
Первый запуск: прямые A-записи без HTTP-прокси/CDN и без AAAA до настройки IPv6.

## 1. Получить конкретную версию

Скачать архив и файл суммы из одного выпуска. Реальные ссылки появятся после
публикации; предполагаемые адреса скачивания использовать не следует.

```bash
sha256sum --check tabula-one-server-v0.2.20-beta.20261024-bundle.3.tar.gz.sha256
mkdir tabula-one-bundle-20261024
tar --no-same-owner -xzf tabula-one-server-v0.2.20-beta.20261024-bundle.3.tar.gz -C tabula-one-bundle-20261024
cd tabula-one-bundle-20261024
./tabula load
```

Все пять образов входят в `images.tar`. После проверки сумм они загружаются
локально; исходники не собираются и образы приложения из реестра не скачиваются.
Интернет для сертификатов и самого проведения интернет-уроков всё равно нужен.

## 2. Настроить свою установку

Использовать три поддомена уже имеющегося домена, например `class.alphacom.us`,
`media.alphacom.us`, `turn.alphacom.us`, направленные на сервер центра.
Основной сайт может оставаться на другом сервере. Все адреса и пример IP ниже
заменить своими. Пример `203.0.113.10` не пройдёт публичную проверку.

```bash
./tabula configure --project=alfakom-beta --site=class.alphacom.us --media=media.alphacom.us --turn=turn.alphacom.us --ip=203.0.113.10 --storage-gib=50
```

Выбрать ёмкость хранилища с запасом для остальных данных. Один раз создаются
`deploy/server/.env`, собственные секреты в `.secrets` и `LC_INSTALLATION_ID`.
Повторная генерация поверх существующей конфигурации запрещена.

В `deploy/server/.env` проверить и явно заменить `LC_BIND=127.0.0.1` на публичный
IPv4 этого сервера. Это подтверждение открытия портов; firewall программа не меняет.
Остальные параметры, имя проекта, идентификатор и UID/GID сохранить.

```bash
./tabula identity
./tabula preflight
./tabula start
./tabula status
```

`preflight` проверяет первый запуск: DNS, адрес интерфейса, конфигурацию, порты,
диск и существующие тома. Ошибка требует разбора, а не удаления данных.
`start` не собирает и не скачивает образы и отказывается использовать тома
с чужим идентификатором установки.

## 3. Создать аккаунты

```bash
./tabula master
./tabula teacher
```

Пароли вводятся скрыто. Первая команда создаёт администратора, вторая — обычного
преподавателя. Существующий email не сбрасывает пароль. Регистрация закрыта.
Для автоматизации можно передать `--stdin-json` и JSON email/password через stdin;
пароли в аргументы командной строки не передавать.

Почта по умолчанию выключена, эти команды работают без неё. Приглашения и
восстановление по email требуют собственных настроек центра. Чужие ключи в
комплект не входят. После первого входа администратор применяет файл бета-разрешения в разделе
«Администрирование → Бета-доступ установки». До этого новые уроки недоступны.
Продление и правила срока описаны в BETA-ACCESS.md; отдельный 120-часовой trial
не ограничивает преподавателей установки с действующим разрешением.

## 4. Проверить и сохранить данные

Проверить обычного преподавателя, PDF/доску, медиафайл и короткий звонок двух
устройств из разных сетей; TURN — по фактическому маршруту. Локальная репетиция
не заменяет публичные DNS, сертификаты и сеть конкретного центра.

```bash
./tabula stop
./tabula start
```

Остановка сохраняет тома, секреты и ID. `down -v`, удаление `.secrets` и смена
имени проекта не являются обновлением. До ценных уроков нужна копия вне сервера:
БД, оба тома Garage, ключи и конфигурация, оформление и данные записей.
Обновления выполняются с копией и учётом миграций; автоматизация пока отложена.

Версии, образы и SHA-256 находятся в `BUNDLE-MANIFEST.json` и файлах сумм.
Уведомления о сторонних компонентах находятся в `notices/`.

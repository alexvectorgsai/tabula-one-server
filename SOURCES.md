# Component source preparation

Binary distribution is held pending completion of corresponding-source preparation. Do not treat this document as a completed license review.

The package uses pinned Linux/amd64 images: application, public edge, PostgreSQL, Garage and LiveKit. Source versions are being matched against their actual Debian and Alpine package inventories, not just product names. This includes FFmpeg/Poppler, system libraries and the libvips native dependency. Garage is a separate unmodified upstream service.

The final release must provide component license notices and matching source packages/build instructions alongside the binaries. Public availability of an unrelated upstream tag does not by itself complete this check. The proprietary application beta terms do not replace or restrict third-party license rights.

No signing private keys, account databases or user materials are included in this repository.
